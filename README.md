# Dashboard Manajemen Tugas Tim (Task Manager)

Aplikasi Web Dashboard Admin interaktif berbasis React 19, Vite, dan Bootstrap untuk mengelola tugas tim berdasarkan prioritas dan status pengerjaan secara client-side.

## Fitur Utama

CRUD Tugas: Tambah, baca, ubah, dan hapus data tugas secara reaktif menggunakan React State.
Manajemen Prioritas:Pengelompokan prioritas tugas High, Medium, Low dengan indikator badg warna.
Status Pengerjaan: Filter status tugas (To Do, In Progress, Done).
Desain Responsif:Dibangun menggunakan komponen dan _utility classes_ dari **React-Bootstrap**.

## Cara Menjalankan Proyek

Ikuti langkah-langkah berikut untuk menjalankan proyek ini di komputer lokal Anda:

1. Clone repositori ini atau unduh kodenya ke komputer lokal Anda.
2. Buka folder proyek melalui terminal (Command Prompt / VS Code Terminal).
3. Instal dependensi / modul yang dibutuhkan dengan menjalankan perintah:
   ```bash
   npm install
   ```
